# Odysseus Ochtrup — Website-Konzept

Modernes, responsives Mehrseiten-Konzept für das Restaurant Odysseus in Ochtrup.

## Enthalten

- Startseite im modernen griechisch-mediterranen Design
- Speisekarte mit Suche, Kategorien und 37 Gerichten
- interaktiver Tischplaner mit Personen- und Preisberechnung
- dreistufige Reservierungsstrecke
- Restaurant-, Kontakt- und Veranstaltungsseite
- Rechtliches und Datenschutzhinweise
- Deutsch, Niederländisch und Englisch
- responsive Darstellung für Desktop, Tablet und Smartphone

## Lokal starten

```bash
npm install
npm start
```

Danach ist die Website unter `http://localhost:4373` erreichbar.

## Hinweis

Dies ist eine unverbindliche Konzeptvorschau. Vor einer finalen Veröffentlichung müssen Betreiberangaben, Preise, Öffnungszeiten, Datenschutzdetails und die technische Zustellung von Reservierungsanfragen vom Restaurant bestätigt beziehungsweise eingerichtet werden.
